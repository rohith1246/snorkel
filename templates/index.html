Terminus 3 Task Architecture Overview

In Terminus 3, tasks run with separate verifier containers (environment_mode = "separate"). The verifier container sees only declared artifacts copied from the main container, requiring tests/Dockerfile and README.md.

⚡ Quick Start Steps:
  1. Click Download Starter Template (.zip) or Featured Demo Task above.
  2. Extract the ZIP and inspect task.toml, instruction.md, and tests/Dockerfile.
  3. Test locally using stb harbor run -a oracle -p . in Ubuntu terminal.
  4. Drag & drop your updated ZIP into the Terminus 3 Task Auditor to get a 100/100 score!
